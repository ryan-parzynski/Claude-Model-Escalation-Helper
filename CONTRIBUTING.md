# Contributing

## Adding a New Trigger

1. Observe the pattern — what Haiku struggle did you catch?
2. Test it — did your 5 existing triggers miss it?
3. Document it — add to `docs/triggers.md`
4. Create PR with evidence from `data/measurements.json`
5. Get Sonnet's opinion (create issue with `escalation-review.md` template)

## Refining Policy

1. Create issue: `escalation-review.md` template
2. Get review: Sonnet evaluates evidence
3. PR: Update `docs/policy.md` or `docs/triggers.md`
4. Measure: Track if refinement improves decisions

## Updating Model Reference

Quarterly (Jan/Apr/Jul/Oct):
1. Check https://claude.com/pricing
2. Update `docs/model-reference.md`
3. Create PR: "Q1 2027: Update model reference"
